🚀 KumarBuildsPro – All-in-One Tools

KumarBuildsPro is a modern, responsive and user-friendly website that provides multiple useful tools in one place. Built using HTML, CSS and JavaScript.

✨ Features

- 🧮 Calculator – Perform basic calculations.
- 📝 Word Counter – Count words, characters and sentences.
- 📒 My Notes – Save, open and delete notes.
- 📏 Unit Converter – Convert length, weight and temperature.
- ✅ To-Do List – Manage daily tasks.
- ⏱️ Stopwatch – Track your time.
- 🎨 Color Picker – Select and copy color codes.
- 🎲 Random Number Generator – Generate random numbers.
- 💾 Backup Center – Download and restore your saved data.

🌟 Highlights

- Modern and clean UI.
- Fully responsive design.
- Dark and Light Mode.
- Local Storage support.
- JSON Backup and Restore.
- Download Notes and Tasks as TXT files.
- No account required.
- Easy to use on mobile and desktop.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
